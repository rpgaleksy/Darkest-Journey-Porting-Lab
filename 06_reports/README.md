# 06 – Reports

Hier landen erzeugte Inventare, Parserausgaben, Map-Übersichten, Ressourcen-
und Referenzanalysen, Switch-/Variablengraphen sowie spätere
Kompatibilitätsberichte.

`resources.json` und `resources.md` stammen aus einem read-only Lauf von
`02_parsing/scan_resources.py` über das unveränderte Originalprojekt. Sie
enthalten nur die bekannten Ressourcenreferenzen, Dateimetadaten und
Prüfsummen; das Original und das RTP werden nicht in dieses Repository
kopiert.
